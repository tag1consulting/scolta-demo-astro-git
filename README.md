# GitMastery (Astro) — Multilingual Git Documentation Site

A comprehensive Git documentation site built on **Astro**, showcasing
[Scolta](https://tag1consulting.com/scolta) AI-powered search across **1,426
pages in 5 languages** (EN/ES/FR/IT/DE).

The Astro sibling of the Drupal [`git-manual`](../git-manual), Django
[`git-manual-django`](../git-manual-django), Next.js
[`git-manual-next`](../git-manual-next), and Nuxt
[`git-manual-nuxt`](../git-manual-nuxt) demos, on the
[`scolta`](../../packages/scolta-node) binding +
[`scolta-astro`](../../packages/scolta-astro) integration. Same corpus, same
five languages, same Scolta config, and **URL-compatible slugs** with all the
other demos.

## Content

`content/` is the identical YAML corpus: 285 English docs + 1 About, each
translated into es/fr/it/de — 1,426 indexable pages (see `SOURCES.md`). URLs
match the other demos: EN at `/<slug>/` (Django-compatible `slugify(title)`),
translations at `/<lang>/<slug>/`, About at `/about/`.

## Quick start

```bash
npm install --legacy-peer-deps
npm run dev                # dev server at http://localhost:4321
# or a server build:
npm run build              # astro build (postbuild copies assets + builds index)
node dist/server/entry.mjs # serve the production build at :3000 (HOST/PORT env)
```

`postbuild` runs `scolta:assets` (copies the vendored runtime bundle into
`public/scolta/`), `scolta:build` (writes the index to `public/pagefind/`,
content mode), and `scripts/sync-static.mjs` (copies both into `dist/client/`,
the only dir the `@astrojs/node` adapter serves static files from — `astro
build` snapshots `public/` before postbuild runs). Set `SCOLTA_API_KEY=sk-ant-...`
for live AI overviews; search works without it.

## How it works

- `astro.config.mjs` registers the **scolta-astro** integration, which injects
  the AI endpoints at `/api/scolta/v1/*` and serializes the demo's Scolta
  config (from `lib/config.ts`) into the server bundle.
- `lib/content.ts` — the same content loader as the Next/Nuxt demos (js-yaml +
  Django-parity slugs/URLs).
- `lib/source.ts` / `lib/config.ts` — the Scolta content source + config
  (`reference` preset, five languages, facet filters), shared by the build and
  the integration. No indexing/scoring logic lives here — it is all in `scolta`.
- Pages render server-side from a build-time content manifest
  (`lib/content-manifest.ts`, generated by `gen:content`); the search widget
  (`ScoltaSearch.astro` from scolta-astro) sits in the global header with a
  per-page `currentLanguage` lock.
